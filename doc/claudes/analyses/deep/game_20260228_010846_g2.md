## Findings

- **Mana plan stale short IDs** (Opus Sport): 4 `IllegalArgumentException: Unknown short ID` crashes during mana auto-pay for Scholar of the Lost Trove. IDs p17, p18, p20, p21 were in the mana_plan but not in ShortIdRegistry. The bridge returned `success: true` to the LLM but the cast silently failed. LLM had to retry 3+ times across two main phases. Root cause: namespace collisions before #640, AND `resolve()` at BridgeCallbackHandler.java:5096 throws instead of gracefully cancelling. Already mostly fixed by #640 (18698d3) — namespace separation prevents the specific collision. Filed `mana-plan-resolve-uncaught-exception` for the remaining edge case (fabricated IDs).
- **Blocker format mismatch** (Heckler): Sent `[" id "," p44 ","blocks","p13"]` instead of `["p44:p13"]`. Self-corrected on retry. Already fixed by #663 (8360142) — system prompt now teaches correct string format.
- **Model behavior (Grok 4.1 Fast)**: Excessive priority passing — 16 runs of 2-3 consecutive `answer:false`, 56% empty `get_action_choices` calls, almost no use of `until` parameter on `pass_priority`. Wastes API calls but doesn't break the game.
- **Model behavior (Grok 4.1 Fast)**: Heckler personality sent zero chat messages despite being designed to trash-talk. Opus Sport (sportsman) sent 4 sportsmanlike messages.
- **Model behavior (Grok 4.1 Fast)**: Cache hit rate reported as >100% (e.g., 199%) in pilot logs. The API reports `cached_tokens > prompt_tokens`, suggesting Grok counts `prompt_tokens` as non-cached only. Cosmetic log issue, no functional impact.
- **Model behavior (Grok 4.1 Fast)**: No visible thinking traces in pilot log — makes debugging model decisions impossible.
