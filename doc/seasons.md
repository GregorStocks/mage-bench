# Season Lifecycle

A season is:

1. A regular season of normal games
2. A championship draft
3. A single-elimination tournament
4. A handoff into the next regular season

The authoritative state lives in `data/season.json`:

```json
{
  "current_season": 2,
  "phase": "regular-season",
  "tournament": null
}
```

`tournament` is `null` during the regular season. Once a championship bracket exists, it points at `data/tournaments/season-N.json`.

## Phases

There are three phases:

- `regular-season`: normal `make run` games are allowed
- `tournament`: the current season's championship is active; regular-season games are blocked
- `between-seasons`: the champion has been crowned, but the next season has not been started yet; regular-season games are still blocked

## Full Flow

### 1. Regular Season

Run games normally:

```bash
make run
make run CONFIG=round-robin-commander
```

Each game is tagged with `current_season` from `data/season.json`.

`make run` already performs the normal post-game export/upload flow. `make export-game GAME=...` is for re-exporting an existing log directory, not the standard way to publish a fresh game.

Ratings and website data are generated by `make leaderboard`:

- `website/src/data/benchmark-results.json`: combined rated leaderboard
- `website/public/data/benchmark-results-season-N.json`: per-season leaderboard data
- `website/src/data/season.json`: copied from `data/season.json` for Astro pages

Leaderboard rules:

- Season 0 games remain viewable but are not rated
- Only `season >= 1` games contribute to the combined rated leaderboard
- Tournament games are excluded from leaderboard ratings

### 2. Conclude the Season

Create a championship bracket from the combined leaderboard:

```bash
make conclude-season
make conclude-season SIZE=16
```

`make conclude-season` runs `make leaderboard` first, then `python -m magebench.cli.conclude_season`:

1. Reads `website/src/data/benchmark-results.json`
2. Selects the top `SIZE` models by combined Elo
3. Maps each leaderboard entry back to a preset in `puppeteer/presets.json`
4. Assigns each entrant a unique random personality from `puppeteer/personalities.json`
5. Creates `data/tournaments/season-N.json`
6. Updates `data/season.json` to `phase: "tournament"` and sets `tournament` to the new file

The initial tournament JSON contains:

- `size`
- `best_of: 3`
- `elimination: "single"`
- `entrants`
- `rounds: []`

`conclude_season.py` also refreshes `website/src/data/season.json` immediately after updating `data/season.json`, so the site sees the new phase without waiting for another leaderboard rebuild.

### 3. Tournament Draft

Each entrant drafts two Jumpstart half-decks:

```bash
make tournament-draft
```

Current implementation details:

1. Samples a random pool of `4 * num_entrants` packs
2. Uses a straight draft order, not a snake draft:
   `1, 2, ..., N, 1, 2, ..., N`
3. Shows the full remaining pool on every pick, sorted by theme
4. Retries until the model responds with a parseable bare option number
5. Writes progress back to the tournament JSON after every pick
6. Builds final `.dck` decklists after all entrants have two packs

The draft data is stored under `tournament["draft"]` and includes:

- `history_version`
- `packs_per_player`
- `pool`
- `picks`
- `decklists`
- `total_cost_usd`

A raw JSONL log of all LLM draft calls is written to:

```text
~/.mage-bench/logs/draft_YYYYMMDD_HHMMSS/draft.jsonl
```

### 4. Tournament Matches

Run championship matches:

```bash
make tournament-game
make tournament-game GAMES=3
```

Current implementation details:

1. Requires `tournament["draft"]` to exist
2. Pre-generates the entire bracket up front
3. Uses seeded fold pairings for round 1
4. Runs best-of-3 matches
5. Exports finished tournament games immediately
6. Regenerates website data at the end of the command

First-round pairings:

- 8 players: `(1,8), (4,5), (2,7), (3,6)`
- 16 players: `(1,16), (8,9), (4,13), (5,12), (2,15), (7,10), (3,14), (6,11)`

`GAMES=N` means "play up to N ready matches", and ready matches in the current round can run in parallel on one shared XMage server.

The runner writes temporary files to:

- `tmp/tournament-decks/`
- `tmp/tournament-configs/`

Tournament match configs set:

- `tournamentGame: true`
- `skipPostGamePrompts: true`

When the bracket finishes, `python -m magebench.cli.tournament_game`:

1. Writes `champion_seed` to the tournament JSON
2. Writes `completed_at` to the tournament JSON
3. Changes `data/season.json` from `phase: "tournament"` to `phase: "between-seasons"`

At that point the champion is known, but `current_season` has not advanced yet.

### 5. Start the Next Season

Advance from a crowned champion to the next regular season:

```bash
make conclude-tournament
```

`python -m magebench.cli.conclude_tournament` requires:

- `data/season.json` to be in `between-seasons`
- the current tournament file to exist
- `champion_seed` to already be recorded

Then it:

1. Verifies the recorded champion matches the finals result
2. Increments `current_season`
3. Sets `phase` back to `regular-season`
4. Clears `tournament` to `null`
5. Leaves the old tournament JSON in `data/tournaments/`

`conclude_tournament.py` also refreshes `website/src/data/season.json` immediately after updating `data/season.json`.

## Enforcement

- `magebench.orchestration.orchestrator._check_regular_season_block()` blocks normal games unless `phase == "regular-season"`
- During `tournament`, the error explains that regular-season games are not allowed during tournaments
- During `between-seasons`, the error explains that a champion has been crowned and the next season has not started yet
- Tournament configs bypass the block by setting `tournamentGame: true`
- Other configs can also bypass the block by setting `skipPostGamePrompts: true`

## Key Files

| Path | Purpose |
| --- | --- |
| `data/season.json` | Authoritative current season state |
| `data/tournaments/season-N.json` | Championship entrants, draft, bracket, and champion for season `N` |
| `website/src/data/season.json` | Generated copy of `data/season.json` used by Astro |
| `website/src/data/benchmark-results.json` | Combined rated leaderboard |
| `website/public/data/benchmark-results-season-N.json` | Per-season leaderboard data |
| `src/magebench/cli/conclude_season.py` | Creates the bracket and enters tournament phase |
| `src/magebench/cli/tournament_draft.py` | Runs the championship draft |
| `src/magebench/cli/tournament_game.py` | Runs tournament matches and crowns the champion |
| `src/magebench/cli/conclude_tournament.py` | Advances to the next regular season |

## Command Summary

```bash
# Regular season
make run [CONFIG=...]
make leaderboard

# Championship setup
make conclude-season [SIZE=8|16]
make tournament-draft

# Championship matches
make tournament-game [GAMES=N]

# Next season
make conclude-tournament
```
