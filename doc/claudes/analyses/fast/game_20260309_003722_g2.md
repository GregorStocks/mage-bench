This matches existing open issues `issues/game-choose-choice-choice-param-returns-short-id-error.json` and `issues/export-decisions-drop-successful-choose-action-retries.json`; no new issue filed.
- Non-critical tool and LLM failures were light and recoverable. Gem3P hit the misleading Thriving color error above, one later `invalid_choice` retry (`choice="p10"` during a color picker), a 120s timeout, and the already-documented Gemini function-response adjacency 400. That Gemini bug was documented in commit `e5c61d3719` and fixed on March 12, 2026 by `0d95fb40b9` (`Fix stale pilot prompts and tool summary truncation`), so no new issue filed. GPT54's only notable tool mistake was a harmless `get_game_log` call with mutually exclusive `cursor` and `since_turn`.
- No reasoning samples for either model, so `llm_reasoning.py` was empty. Chat stayed light and board-focused; no personality infection.
