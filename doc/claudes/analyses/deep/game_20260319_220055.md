**Players**: G31FL Spike (gemini-3.1-flash-lite-preview, spike) vs Son46 Memoir (claude-sonnet-4.6, memoir)
**Format**: Limited (Jumpstart: Devilish + Discarding 1 vs Cruel + Doctor)
**Result**: Game never started; both bridge pilots exited before joining the table
**Config**: round-robin-jumpstart

## Findings

- Both pilots died before any LLM activity because `BridgeClient.loadDeck()` rejected line 1 `NAME:...` in the generated Jumpstart `.dck` files. Fixed on this branch by teaching the bridge parser to accept standard `.dck` metadata/header lines and alphanumeric collector numbers.
- The observer later crashed in its table-polling threads with `NoClassDefFoundError: org/jboss/mx/util/ObjectNameFactory`, which turned the summary into `spectator_crashed` and prevented website export. Fixed on this branch by adding a small `org.jboss.mx.util.ObjectNameFactory` compatibility shim to `mage-common`.
- No gameplay happened. Both `*_llm.jsonl` files only record `game_end`, and total cost stayed at `$0.0000`.

## Notes

- The console reports `G31FL Spike` exiting first, but `Son46 Memoir` failed the same way on its own generated Jumpstart deck.
- The website export failure is downstream noise. The first real breakage is the bridge deck parser rejecting standard `.dck` headers.
