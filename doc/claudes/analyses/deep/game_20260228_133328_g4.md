# game_20260228_133328_g4

**Players**: Kimi25 Valley (moonshotai/kimi-k2.5, Faeries+Gross) vs MiMo Coach (xiaomi/mimo-v2-flash, Knights+Demons)
**Format**: Limited (Jumpstart)
**Result**: MiMo Coach won on turn 13 (Kimi25 Valley to -1 life)
**Config**: round-robin-jumpstart

## Findings

- **P3 filed**: `include-next-action-message-in-choose-action-response` — `choose_action` response doesn't include next action's message text when `next_action_pending=true`. Kimi-k2.5 guessed wrong about a GAME_ASK ward prompt and lost its Strangling Spores for nothing.
- **Model issue (kimi-k2.5)**: Valley-girl personality overrode strategic play. Model refused to block or attack based on flavor reasoning ("I'm NOT sacrificing my cute little Hippocamp"), never dealt a single point of damage in 13 turns.
- **Model issue (kimi-k2.5)**: Misinterpreted ward payment prompt as asking the opponent, answered `false` (decline to pay), countering its own spell. Never realized the spell fizzled.
- **Model issue (kimi-k2.5)**: On Turn 12 at 6 life with opponent tapped out, had Yargle (9/3) in hand — should have slammed it for lethal. Instead cast Strangling Spores precombat targeting the wrong creature (BHG instead of Kwende) into ward.
- **Model issue (mimo-v2-flash)**: 3 stale-ID errors from skipping `get_action_choices` — references objects visible in game state but not in current choices.
- **Model issue (mimo-v2-flash)**: ~11% empty response rate (10 of 88 LLM calls returned empty). Retry mechanism handled it but added latency.
- **Model issue (mimo-v2-flash)**: Cast Chains of Custody on own Benalish Honor Guard when opponent had zero nonland permanents — wasted premium removal for just ward {2}.
- **Infrastructure**: 26 lost callback recoveries for MiMo, 8 for Kimi. Worst was 60s absolute silence. Most were during opponent's thinking time — expected behavior, not a bug.

## Notes

- kimi-k2.5 with valley-girl personality is strategically terrible. The personality completely overwhelms the "competitive player" directive. Thinking traces are 2-3x longer than MiMo's, spending tokens on flavor instead of game analysis. Cost 3.7x more ($0.32 vs $0.09) and played dramatically worse.
- mimo-v2-flash plays fast and cheap but has mechanical reliability issues. Its strategy was sound (curve out, attack every turn) despite many technical errors. The bridge's auto-populate and retry mechanisms effectively compensate.
- Kimi misread MiMo's trash talk ("Nice deck, thanks for the win", "gg") as concession and passed priority. Models shouldn't interpret chat as game state.
- The ward prompt confusion is a systemic risk: any model that skips `get_action_choices` before a GAME_ASK will be flying blind. The fix (including message text in choose_action response) is low-cost and would prevent this class of error.
