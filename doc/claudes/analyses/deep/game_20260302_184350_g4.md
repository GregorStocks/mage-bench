## Findings

- **get_action_choices missing @Tool.Field for `current_step`** — Hit GptOSS twice in Turn 1. Already fixed in PR #797 (58accffd5d), which postdates this game's commit (3eaf2996e3).
- **gpt-oss-120b hallucinated action batching** — Seq 75: model emitted 21 tool calls in one response, 5 with malformed JSON (missing opening braces). Caused a 64-second stall + JSONDecodeError. Already documented in `doc/investigating-game-logs.md` as a known gpt-oss pattern.
- **gpt-oss-120b hallucinated world state** — After context trim from the JSONDecodeError, model hallucinated Plains, Islands, and Serenade of the Siren (cards not in any deck). Recovered when pass_priority returned fresh board state.
- **gpt-oss-120b empty responses** — Two consecutive empty LLM responses (seq 84, 88) where model spent 2,210 and 684 reasoning tokens but produced no output. Retry logic handled both.
- **gpt-oss-120b kept 7-land hand** — Catastrophic mulligan: kept 4 Forest + 3 Mountain with zero spells. Model behavior.
- **Haiku p32 unknown ID** — Haiku tried to cast Soul's Might by hallucinated ID `p32` (not in choices). Self-corrected immediately to Benevolent Hydra (p33).
- **Lost callback recovery** — Both bridges fired speculative passes during opponent's slow LLM turns. Haiku had 20+ lost-callback warnings because GptOSS was consistently slow. Normal cascading behavior, not a bug.
- **No personality infection** — Sardonic personality did not bleed into GptOSS reasoning traces. Sportsman personality clean for Haiku. Chat messages had mild flavor but gameplay decisions were mechanical.

## No new issues filed
