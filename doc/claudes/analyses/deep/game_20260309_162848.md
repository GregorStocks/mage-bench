# game_20260309_162848

**Players**: Opus Brewer (anthropic/claude-opus-4.6) vs Gem3P Coach (google/gemini-3-pro-preview)
**Format**: Limited, Two Player Duel
**Result**: Gem3P Coach won on turn 6 after Opus Brewer timed out
**Config**: seed1-vs-seed3

## Findings

- **P1 filed**: `pass_priority(until=stack_resolved) hangs if stack clears on passive updates` — Opus cast Elvish Rejuvenator, then called `pass_priority(until="stack_resolved")`. The trigger finished and the stack emptied at `16:35:15`, but the bridge stayed blocked until the match timer expired at `17:34:05`. Root cause is `BridgeCallbackHandler.passPriority()` only checking `yieldUntilStackResolved` while `pendingAction != null`, so passive `GAME_UPDATE` callbacks can clear the stack without waking the wait.
- **Not filed (already tracked elsewhere)**: Gem3P Coach hit one Gemini provider 400 (`Please ensure that function response turn comes immediately after a function call turn.`). This matches the already-documented adjacency/stale-history problem; no new issue from this game.
- **Not filed (model behavior)**: Gem3P Coach made poor mulligan bottoms and Opus briefly tried `choose_action(choice="p12")` on the opponent's turn, but the tool output was correct and these were model mistakes rather than bridge bugs.
